# Camera 2.0 model assets

The ONNX files and their Apache 2.0 license are generated build inputs and are
not stored in Git. Download and verify the pinned assets with:

```powershell
.\eye\fetch-models.ps1
```

Use `-CheckOnly` to verify an existing offline copy. Versions, immutable source
revisions, expected sizes and SHA-256 hashes are recorded in `models.json`.
